# ONG PARE

Este é o repositório do projeto **ONG PARE**, uma aplicação web desenvolvida para simular a plataforma digital de uma organização voltada ao apoio educacional e social. O projeto foca na otimização de performance, modularização de código e fluxo real de deploy em ambiente de produção.

## 🔗 Link em Produção
Acesse a aplicação no ar: **[https://ongpare.vercel.app](https://ongpare.vercel.app)**

## 🚀 Tecnologias Utilizadas
* **HTML5 & CSS3:** Estruturação semântica e estilização responsiva.
* **JavaScript (ES6+):** Manipulação de DOM, modularização (`type="module"`) e navegação dinâmica.
* **Vite:** Ferramenta de build (empacotador) para minificação de código e otimização de assets.
* **SweetAlert2:** Biblioteca externa para alertas e modais interativos.
* **Vercel:** Hospedagem em nuvem com integração e entrega contínuas (CI/CD).
* **Git & GitHub:** Controle de versão e gestão de repositório.

## ⚙️ Funcionalidades e Estrutura
* **Single Page Application (SPA):** Transição entre as telas (Início, Projetos, Cadastro) gerida por JavaScript, sem recarregamento completo da página no navegador.
* **Gestão de Recursos Estáticos:** Uso da diretriz `public` para garantir que páginas secundárias e imagens sejam corretamente compiladas e servidas pelo servidor da Vercel.
* **Otimização de Performance:** Arquitetura empacotada que reduz o tamanho dos arquivos finais (HTML/CSS/JS) para carregamento instantâneo.
